Contexto

Problema y objetivo

Qué se quiso resolver y hasta dónde llega el proyecto

  • La voz es una interfaz natural, pero implementarla desde cero exige modelos propios.
  • Azure ofrece el servicio ya entrenado: solo hay que integrarlo bien.
  • Objetivo: app web con texto a voz y voz a texto.
  • Límite: sin usuarios, sin base de datos, sin despliegue.
  • Condición: la clave no llega al navegador.

Parte 2 · Código

Texto a voz en el servidor

Se valida la entrada y se devuelve un MP3 generado en memoria

const cfg = sdk.SpeechConfig.fromSubscription(KEY, REGION);
cfg.speechSynthesisVoiceName = voice;      // es-CO-SalomeNeural
cfg.speechSynthesisOutputFormat =
  sdk.SpeechSynthesisOutputFormat.Audio16Khz128KBitRateMonoMp3;

const synth = new sdk.SpeechSynthesizer(cfg, null);
synth.speakTextAsync(text, (result) => {
  synth.close();
  res.set("Content-Type", "audio/mpeg");
  res.send(Buffer.from(result.audioData));
});

Validaciones previas: texto no vacío · máximo 500 caracteres · voz dentro del catálogo.

Parte 2 · Seguridad

Token temporal para el navegador

El servidor cambia la clave por un token que caduca en unos 10 minutos

// server/index.js
const r = await fetch(
  `https://${REGION}.api.cognitive.microsoft.com/sts/v1.0/issueToken`,
  { method: "POST",
    headers: { "Ocp-Apim-Subscription-Key": KEY } });
res.json({ token: await r.text(), region: REGION });
  • Si el token se filtra, caduca solo; la clave permanece privada.
  • Se pide uno nuevo cada vez que se inicia la grabación.

Parte 2 · Código

Voz a texto en el navegador

Reconocimiento continuo con texto parcial y texto final

const { token, region } = await (await fetch("/api/token")).json();
const cfg = sdk.SpeechConfig.fromAuthorizationToken(token, region);
cfg.speechRecognitionLanguage = lang;      // es-CO
const rec = new sdk.SpeechRecognizer(
  cfg, sdk.AudioConfig.fromDefaultMicrophoneInput());

rec.recognizing = (_s, e) => setPartial(e.result.text);
rec.recognized  = (_s, e) => addFinal(e.result.text);
rec.startContinuousRecognitionAsync();

Al detener o cambiar de pestaña se cierra el reconocedor para liberar el micrófono.

Aprendizaje

Habilidades que se pusieron en práctica

  • Cloud: crear y configurar un recurso, claves, regiones, planes y costos
  • Backend: API REST con Express, validación de entradas, manejo de errores
  • Frontend: React con hooks, estado, efectos y limpieza de recursos
  • Seguridad: secretos en variables de entorno, tokens de corta vida
  • Integración: uso de un SDK en cliente y servidor
  • Calidad: mensajes de error claros, accesibilidad básica, documentación
9
Cierre

Conclusiones

  • Un servicio en la nube se integra con poco código si se separan bien las responsabilidades.
  • La clave se queda en el servidor; el navegador solo recibe tokens temporales.
  • Siguientes pasos: traducción en vivo, guardar historial, desplegar en Azure App Service.
