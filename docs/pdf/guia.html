1. Configuración en Azure

1.1 Crear el recurso Speech

  1. Ingresar a portal.azure.com con la cuenta de Azure.
  2. Buscar Speech (Azure AI Services) y pulsar Crear.
  3. Completar el formulario:
CampoValor sugerido
SuscripciónLa propia (p. ej. Azure for Students)
Grupo de recursosNuevo: rg-speech-demo
Regióneastus o brazilsouth (anotarla)
NombreÚnico, p. ej. speech-demo-tunombre
Plan de tarifaFree F0 si está disponible; si no, Standard S0
  1. Revisar y crear → Crear → Ir al recurso.

1.2 Obtener clave y región

En el recurso: Claves y punto de conexión. Copiar KEY 1 y la Región.

1.3 Guardarlas en el proyecto

Copy-Item server/.env.example server/.env

# server/.env
SPEECH_KEY=<KEY 1>
SPEECH_REGION=eastus
PORT=3001
Seguridad. server/.env está en .gitignore. Si la clave se llega a publicar, usar Regenerar clave en el mismo panel. Al terminar la exposición se puede borrar el grupo de recursos para evitar cobros.

1.4 Verificar

npm run dev
curl http://localhost:3001/api/health   # {"ok":true}
curl http://localhost:3001/api/token    # {"token":"...","region":"eastus"}

2. Integración en el código

La aplicación usa el mismo SDK (microsoft-cognitiveservices-speech-sdk) en dos lugares, con credenciales distintas:

NavegadorReact + Vite
⇄
ServidorExpress :3001
→
Azure Speechclave en el servidor
FunciónSDK corre enCredencial
Texto a vozServidorClave (fromSubscription)
Voz a textoNavegador (necesita micrófono)Token de ~10 min (fromAuthorizationToken)

2.1 Texto a voz — server/index.js

const speechConfig = sdk.SpeechConfig.fromSubscription(SPEECH_KEY, SPEECH_REGION);
speechConfig.speechSynthesisVoiceName = voice;   // es-CO-SalomeNeural
speechConfig.speechSynthesisOutputFormat =
  sdk.SpeechSynthesisOutputFormat.Audio16Khz128KBitRateMonoMp3;

const synthesizer = new sdk.SpeechSynthesizer(speechConfig, null);
synthesizer.speakTextAsync(text, (result) => {
  synthesizer.close();
  res.set("Content-Type", "audio/mpeg");
  res.send(Buffer.from(result.audioData));
});

Antes se valida que el texto no esté vacío, que tenga máximo 500 caracteres y que la voz exista en el catálogo (voices.js).

2.2 Token temporal — server/index.js

const r = await fetch(
  `https://${SPEECH_REGION}.api.cognitive.microsoft.com/sts/v1.0/issueToken`,
  { method: "POST", headers: { "Ocp-Apim-Subscription-Key": SPEECH_KEY } });
res.json({ token: await r.text(), region: SPEECH_REGION });

2.3 Voz a texto — SpeechToText.jsx

const { token, region } = await (await fetch("/api/token")).json();
const speechConfig = sdk.SpeechConfig.fromAuthorizationToken(token, region);
speechConfig.speechRecognitionLanguage = lang;
const recognizer = new sdk.SpeechRecognizer(
  speechConfig, sdk.AudioConfig.fromDefaultMicrophoneInput());

recognizer.recognizing = (_s, e) => setPartial(e.result.text);  // parcial
recognizer.recognized  = (_s, e) => { /* frase final */ };
recognizer.startContinuousRecognitionAsync();

2.4 Reproducción

El cliente envía POST /api/tts, recibe el MP3 como Blob, genera una URL con URL.createObjectURL y la asigna a la etiqueta <audio>. La URL se libera al desmontar el componente.

3. Uso de la aplicación

3.1 Arranque

npm run install:all
npm run dev        # abrir http://localhost:5173

3.2 Texto a voz

  1. Escribir el texto (hasta 500 caracteres).
  2. Elegir idioma; la lista de voces y la frase de ejemplo cambian solas.
  3. Elegir la voz.
  4. Pulsar Escuchar y usar el reproductor.

3.3 Voz a texto

  1. Elegir el idioma de reconocimiento.
  2. Pulsar Iniciar grabación y permitir el micrófono.
  3. Hablar: el texto gris es provisional y se confirma al terminar cada frase.
  4. Detener para terminar; Limpiar para borrar.
